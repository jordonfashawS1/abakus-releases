# Abakus — downloads

Live sports scores, box scores, team and player pages, rankings, soccer, golf and the Abakus Gameday graphic.

**Get the latest version under [Releases](../../releases/latest)** and download the file for your computer:

| Your computer | Download |
|---|---|
| Mac with Apple Silicon (M1, M2, M3, M4 …) | `Abakus-mac-apple-silicon.zip` |
| Mac with an Intel processor | `Abakus-mac-intel.zip` |
| Windows 10 or 11 — installer (recommended) | `Abakus-windows-setup.exe` |
| Windows 10 or 11 — portable, no install | `Abakus-windows.zip` |

Not sure which Mac you have?  → About This Mac: "Chip: Apple M…" is Apple Silicon; "Processor: Intel" is Intel.

**Mac:** unzip, move `Abakus.app` to Applications, and the first time right-click it → Open.
(Keep it in Applications: that's where Abakus can update itself.)

**Windows installer:** run `Abakus-windows-setup.exe`. No administrator password is needed. It adds Abakus to the Start menu
(and the desktop if you tick the box), and you can uninstall it from Settings › Apps.
If Windows shows "Windows protected your PC", click **More info → Run anyway**.

**Windows portable:** unzip the whole folder somewhere you like and run `Abakus.exe`. Nothing is installed.

**Updates:** Abakus checks this page when it starts. When a newer version is out, a banner appears —
click **Update now** and it downloads, installs and reopens by itself. No unzipping needed.

Scores and stats come from ESPN's public data.
Abakus score keeper was created by Jordon Fashaw and Sam Bronson.
