# Abakus — downloads

Live sports scores, box scores, team and player pages, rankings, soccer, golf and the Abakus Gameday graphic.

**Get the latest version under [Releases](../../releases/latest)** and download the zip for your computer:

| Your computer | Download |
|---|---|
| Mac with Apple Silicon (M1, M2, M3, M4 …) | `Abakus-mac-apple-silicon.zip` |
| Mac with an Intel processor | `Abakus-mac-intel.zip` |
| Windows 10 or 11 | `Abakus-windows.zip` |

Not sure which Mac you have?  → About This Mac: "Chip: Apple M…" is Apple Silicon; "Processor: Intel" is Intel.

**Mac:** unzip, move `Abakus.app` to Applications, and the first time right-click it → Open.
**Windows:** unzip the whole folder and run `Abakus.exe`.

Abakus checks this page when it starts and shows a banner when a newer version is available.
Scores and stats come from ESPN's public data.
